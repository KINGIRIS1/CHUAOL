# CHUAOL — Chùa Online

Không gian chùa Việt 3D chạy trên trình duyệt (desktop và điện thoại), xây bằng **Three.js**: dạo bước qua Tam quan, thắp hương, thỉnh chuông, gõ mõ, ngồi thiền, thả đèn hoa đăng và cùng đi lễ với những người khác theo thời gian thực.

Dự án đang ở giai đoạn lập kế hoạch.

- 📜 Kế hoạch phát triển: [`docs/KE_HOACH.md`](docs/KE_HOACH.md)

## Stack dự kiến

- Client: TypeScript, Vite, Three.js (React Three Fiber, drei), Rapier
- Multiplayer: Colyseus (Node.js)
- Dữ liệu: PostgreSQL (Prisma), Redis
- Asset: Blender → glTF/GLB (Meshopt, KTX2), phân phối qua CDN
